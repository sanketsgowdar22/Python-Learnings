# Python Learnings 

A repository dedicated to learning and practising Python programming, starting from the fundamentals and gradually exploring more advanced concepts.

This repository serves as a continuous learning journey, where concepts, examples, and practice programs are added as I learn new things.

##  Topics Covered

- **Python Fundamentals** — Syntax, variables, keywords, and basic programming concepts
- **Data Types and Literals** — Numbers, strings, Boolean values, and other literals
- **Operators** — Arithmetic, comparison, logical, identity, bitwise, and assignment operators
- **Conditional Statements** — Decision-making using conditional logic
- **Strings** — String operations and manipulation
- **Collections** — Lists, dictionaries, and other collection types
- **Problem-Solving** — Basic programming exercises and logical problems

*This list will continue to grow as new concepts are learned and practised.*

##  Requirements

- Python 3
- A code editor such as Visual Studio Code (optional)

## ▶ Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/sanketsgowdar22/Python-Learnings.git
```

**2. Navigate to the project directory**

```bash
cd Python-Learnings
```

**3. Run a Python program**

```bash
python your_program.py
```

Replace `your_program.py` with the name of the Python file you want to execute. Depending on your system, you may need to use `python3` instead of `python`.
